# BỐI CẢNH CODE CỦA SINH VIÊN
```c
#include <stdio.h>

int main() {
    int a, b, c;
    int avg;

    printf("Nhap 3 diem: ");
    scanf("%d%d%d", &a, &b, &c);

    avg = (a + b + c) / 3;

    printf("Diem trung binh: %d", avg);

    return 0;
}

2. Nội dung hội thoại mẫu (8 lượt trao đổi)
* **Lượt 1 – AI:** Chào em, trước khi nhìn vào kết quả chạy, theo em khi nhập `7`, `8`, `9` thì chương trình này sẽ in ra giá trị gì?
* **Lượt 1 – Sinh viên:** Dạ em nghĩ sẽ ra `8` vì `(7 + 8 + 9) / 3 = 24 / 3 = 8`.
* **Lượt 2 – AI:** Đúng là `24 / 3` ra `8`, nhưng nếu đổi input thành `7`, `8`, `8` (tổng là `23`), theo em chương trình sẽ in ra số nào và tại sao không có số lẻ?
* **Lượt 2 – Sinh viên:** Dạ em nghĩ vẫn ra `7` thôi vì biến `avg` khai báo là `int` nên bị cắt phần thập phân.
* **Lượt 3 – AI:** Em nhận ra `int` cắt phần lẻ là tốt rồi, vậy theo em trong biểu thức `(a + b + c) / 3`, phép chia này đang là phép chia nguyên hay phép chia số thực, và nó hoạt động thế nào khi cả tử và mẫu đều là số nguyên?
* **Lượt 3 – Sinh viên:** Dạ là phép chia nguyên, khi hai số nguyên chia nhau thì C bỏ phần dư đi, chỉ giữ phần nguyên.
* **Lượt 4 – AI:** Gợi ý nhỏ cho em: trong C, nếu một trong hai toán hạng của `/` là số thực (ví dụ chia cho `3.0` hoặc ép kiểu `(float)`), kết quả phép chia sẽ thành số thực, đồng thời biến `avg` và `printf` cũng cần kiểu tương ứng. Em thử đề xuất cách sửa cụ thể cho dòng tính toán và dòng `printf` xem?
* **Lượt 4 – Sinh viên:** Dạ em sửa `float avg = (a + b + c) / 3.0;` và `printf("Diem trung binh: %.1f", avg);`.
* **Lượt 5 – AI:** Cách sửa của em đi đúng hướng rồi! `3.0` làm phép chia thành số thực, `avg` là `float` lưu được phần lẻ và `%.1f` in ra 1 chữ số thập phân. Theo em, nếu giữ `3` thay vì `3.0` nhưng vẫn dùng `float avg`, chuyện gì sẽ xảy ra?
* **Lượt 5 – Sinh viên:** À, lúc đó `(a + b + c) / 3` vẫn chia nguyên ra `8` trước rồi mới gán vào `avg`, nên `avg` thành `8.0` chứ không giữ được số lẻ của `23 / 3`.
* **Lượt 6 – AI:** Chính xác, em đã điều chỉnh đúng chỗ mấu chốt rồi! Để chắc chắn em nắm vững bản chất, em hãy tự giải thích lại nguyên lý này bằng một ví dụ khác ngoài điểm số xem?
* **Lượt 6 – Sinh viên:** Dạ ví dụ chia `5` chiếc bánh cho `2` bạn: nếu chia nguyên `5 / 2` thì mỗi bạn được `2` cái (bỏ phần dư), còn chia thực `5 / 2.0` thì mỗi bạn được `2.5` cái.
* **Lượt 7 – AI:** Ví dụ rất trực quan! Vậy trong code C, nếu em viết `float x = 5 / 2;` thì giá trị lưu trong `x` là bao nhiêu và tại sao?
* **Lượt 7 – Sinh viên:** Dạ là `2.0`, vì `5` và `2` đều là số nguyên nên phép chia ra `2` trước, sau đó mới chuyển sang `float` khi gán cho `x`.
* **Lượt 8 – AI:** Tuyệt vời, em đã hiểu rõ và tự sửa được lỗi rồi. Dưới đây là code tham khảo chuẩn để em đối chiếu với bài làm của mình: *(AI cung cấp đoạn code `float` chuẩn)*.
3. Phân tích lỗi trong chương trình ban đầu
1. **Biến `avg` khai báo sai kiểu (`int`):** Chỉ lưu số nguyên, làm mất phần thập phân của điểm trung bình.
2. **Phép chia nguyên `(a + b + c) / 3`:** Cả tổng `(a + b + c)` (`int`) và `3` (`int`) đều là số nguyên nên toán tử `/` thực hiện **integer division** (cắt bỏ phần dư/phần thập phân ngay trong phép chia).
3. **Định dạng in `%d`:** Chỉ in số nguyên, không hiển thị phần thập phân như `8.0` hay `7.7`.
4. Code sau khi tự sửa
```c
#include <stdio.h>

int main() {
    int a, b, c;
    float avg;

    printf("Nhap 3 diem: ");
    scanf("%d%d%d", &a, &b, &c);

    // Chia cho 3.0 để thực hiện phép chia số thực thay vì chia nguyên
    avg = (a + b + c) / 3.0;

    printf("Diem trung binh: %.1f", avg);

    return 0;
}
5. SO SANH int VA float, PHEP CHIA NGUYEN VA PHEP CHIA SO THUC
Tieu chi                   | int / Phep chia nguyen                     | float / Phep chia so thuc
----------------------------------------------------------------------------------------------------------------------------------------
Luu tru gia tri            | Chi luu so nguyen (vd: 7, 8, -2), khong    | Luu so thuc co phan thap phan (vd: 8.0, 7.67),
                           | co phan thap phan.                          | do chinh xac khoang 6-7 chu so thap phan.
----------------------------------------------------------------------------------------------------------------------------------------
Cach phep chia / hoat dong | Khi ca hai ve la so nguyen (a / b), ket    | Khi co it nhat mot toan hang la so thuc
                           | qua bi cat phan le (lam tron ve 0 voi so   | (3.0 hoac ep kieu (float)), ket qua giu
                           | duong/am theo quy tac C).                  | phan thap phan.
----------------------------------------------------------------------------------------------------------------------------------------
Dinh dang printf tuong ung | %d                                         | %f (hoac %.1f, %.2f de gioi han so chu so
                           |                                            | thap phan).
6. Ví dụ mới chứng minh hiểu kiến thức
Ví dụ: Tính tỉ lệ phần trăm số bài đã làmGiả sử bạn có 15 bài tập và đã hoàn thành 7 bài. Tỉ lệ hoàn thành thực tế là $\frac{7}{15} \times 100\% \approx 46.67\%$.C#include <stdio.h>
int main() {
    int da_lam = 7;     // so bai da hoan thanh
    int tong_bai = 15;  // tong so bai tap
    // Sai: da_lam / tong_bai = 7 / 15 = 0 (chia nguyen), nhan 100 van ra 0.0%
    float phan_tram_sai = (da_lam / tong_bai) * 100;
    // Dung: (float)da_lam / tong_bai = 0.4666..., nhan 100.0 ra 46.67%
    float phan_tram_dung = ((float)da_lam / tong_bai) * 100.0;
    printf("Ty le (chia nguyen): %.2f%%\n", phan_tram_sai);
    printf("Ty le (chia thuc):   %.2f%%\n", phan_tram_dung);

    return 0;
}
